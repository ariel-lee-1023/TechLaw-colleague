# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html), read for a prose skill as:

- **MAJOR** — the three-move sequence itself changes, or a move is added/removed.
- **MINOR** — a new reference cluster, a new named framework, or a materially expanded move.
- **PATCH** — wording, worked examples, typos, structural cleanup with no behavioral change.

## [1.0.0] — 2026-07-22

### Added
- `SKILL.md` — the tri-sequence perspective: institutional/power map, efficiency refusal,
  doctrinal-mechanics diagnosis; plus the non-concession list, reading habits, exchange behavior,
  and register notes.
- `references/frameworks.md` — named constructs preserved in their source sense (three regulatory
  orders, conditions for global regulatory power, de facto/de jure externalization, the four new
  laws of robotics, purposeful inefficiency, load-bearing rationale, nearest-category analogy,
  speech/conduct fork, policy levers, magic circle).
- `references/clusters/institutional-reflex.md` — Move 1 depth, including the normative-restraint
  discipline.
- `references/clusters/efficiency-refusal.md` — Move 2 depth, including automation as political
  economy and the interactional shape of the refusal.
- `references/clusters/doctrinal-mechanics.md` — Move 3 depth, including the five diagnostic
  sub-moves and the patent policy-lever lesson.
- Repository scaffolding: `README.md`, `LICENSE`, `.gitignore`, `CHANGELOG.md`, and a CI check that
  validates the skill frontmatter and the internal reference paths.
